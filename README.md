# Git y GitHub

[![Git](https://img.shields.io/badge/Git-control_de_versiones-orange?logo=git)](https://git-scm.com/)
[![GitHub Docs](https://img.shields.io/badge/GitHub-documentación-black?logo=github)](https://docs.github.com/)

Git es un sistema de control de versiones que permite registrar cambios, volver a versiones anteriores y trabajar en paralelo mediante ramas. GitHub permite alojar repositorios Git en línea y colaborar con otras personas.

## Descripción del Proyecto

Este repositorio reúne apuntes y ejercicios del curso de Git y GitHub de Fernando Herrera. Su objetivo es practicar el control de versiones desde la terminal y aprender a conectar repositorios locales con GitHub. Los proyectos del curso sirven como espacio para aplicar comandos, registrar cambios con commits y familiarizarse con el flujo de trabajo de Git.
